cache.novavero.ai

A Nix binary cache. On every push to main, nova-nix's CI publishes to it what it builds for Windows: GNU Hello with everything its build needs, and the toolchain nova-nix builds from a 1,623-byte seed, with the source archives they come from. A build that names the cache downloads what the cache holds instead of building it.

Use it

In nix.conf, or in NIX_CONFIG:

extra-substituters = https://cache.novavero.ai
extra-trusted-public-keys = cache.novavero.ai-1:9gQ7tLWMM+2tdC9H5sKMJltDIPfD7X2GWlZe8Aa8hHQ=

Or for one build:

nova-nix build FILE.nix --substituter https://cache.novavero.ai --trusted-key cache.novavero.ai-1:9gQ7tLWMM+2tdC9H5sKMJltDIPfD7X2GWlZe8Aa8hHQ=

The cache signs every narinfo with that key, and a client takes nothing the key does not sign.

Protocol

The Nix binary cache protocol over HTTPS, for the store directory /nix/store: /nix-cache-info, /<hash>.narinfo and /nar/<file>.

Software

The server is nova-cache, the Nix binary cache protocol in Haskell. Native Windows builds in nova-nix describes the builds it serves.
