- **`nova-cache-server` serves no landing page of its own: `GET /` answers the library's line of plain text, or, given `--root-page FILE`, that file as HTML.** The executable served cache.novavero.ai's branded page to every operator who ran it, with that deployment's name, styling and links, where the library has kept the root page per deployment through `scRootResponse` all along. A deployment's page is now a file it ships beside its unit, as upstream's cache.nixos.org serves a static page at its root; the public cache's is `deploy/index.html`, styled by novavero.ai's stylesheets. The server reads the file once at startup and refuses to start if it cannot. The library gains `htmlRootResponse` in `NovaCache.Server`. Nix clients never request `/`, so substitution is unchanged.
- **The server writes its log to stdout line by line.** Under systemd its stdout is a pipe to the journal, where GHC buffered it by block, so the startup lines and each request's line reached the journal only when a block filled.
